## Validation so far

The endpoint probe and ElevenLabs transport were exercised with controlled mock endpoints; no live provider credentials were available. A later audit caught the Responses adapter omitting version tone/language/disclosure instructions; it now transmits those immutable settings as system instructions with a regression test.
- Browser Use slice: pinned the open-source Python package to `browser-use==0.13.10`, mapped Actor operations to the existing remote contract, added a bounded read-only `Agent` research action and an internal model gateway that keeps the external key out of the browser container. The gateway pins public DNS and permits only Chat Completions for the configured model. Per-session HTTPS CONNECT proxy, private screenshot cleanup, policy and token checks are wired. A two-session drill exposed the old 256 PID limit; the final Docker profile uses a two-session worker cap, 1024 PID and 2 GiB memory limits. After the old driver was removed, `bun scripts/phase6-browser-integration.ts` passed open/extract/type/click/screenshot/close, denial, cancellation, timeout, and safe progress. `bun scripts/phase7-browser-restart.ts` passed two-tenant page and screenshot isolation, stale-session rejection after worker restart, and new-session recovery. `bun run check` passed with 73 tests and 396 assertions.
