2. Provider configuration — official OpenAI SDK, endpoint capability validation, primary/fallback vision, ElevenLabs configuration, mocked contract tests, live endpoint drill when credentials are provided.

## Validation so far

- Provider slice: `bun run check` passed with 72 tests and 393 assertions. `bun run admin:build` and `bun run client:build` passed. The endpoint probe and ElevenLabs transport were exercised with controlled mock endpoints; no live provider credentials were available.
- Browser Use slice: pinned the open-source Python package to `browser-use==0.13.10`, mapped Actor operations to the existing remote contract, added a bounded read-only `Agent` research action and an internal model gateway that keeps the external key out of the browser container. The gateway pins public DNS and permits only Chat Completions for the configured model. Per-session HTTPS CONNECT proxy, private screenshot cleanup, policy and token checks are wired. A two-session drill exposed the old 256 PID limit; the final Docker profile uses a two-session worker cap, 1024 PID and 2 GiB memory limits. After the old driver was removed, `bun scripts/phase6-browser-integration.ts` passed open/extract/type/click/screenshot/close, denial, cancellation, timeout, and safe progress. `bun scripts/phase7-browser-restart.ts` passed two-tenant page and screenshot isolation, stale-session rejection after worker restart, and new-session recovery. `bun run check` passed with 73 tests and 396 assertions. Live model-backed research remains unverified without an approved endpoint/key.
- Web Chat slice: `0010_great_mephisto.sql` migrated cleanly on a fresh PostgreSQL database. `bun scripts/phase7-webchat-integration.ts` passed site and session authorization, rate/tenant/origin controls, inbox dedupe/sequence, real adapter execution from a fake-model batch, poll, handoff, and revocation. A built Next.js server passed a controlled HTTP drill covering preflight, bootstrap, send, dedupe, poll, origin denial, and revocation. `bun run check` passed with 74 tests and 404 assertions; `bun run admin:build` passed. Merchant-site acceptance and human staff reply UI remain open.
- Comment slice: `0011_nervous_william_stryker.sql` migrated on a fresh PostgreSQL database. The DB drill passed signed feed receipt, replay, policy/tenant checks, controlled fake-Meta capability verification, keep/handoff, draft runtime reply, hide, ambiguous write, Page-author guard, and human ownership. `bun run check` passed with 78 tests and 435 assertions. Both production builds passed. Actual Meta Page/token/app approval and observed Page writes remain external release gates.
- Trial slice in progress: `0012_tidy_stature.sql` adds expiry behavior; `0013_legacy_trial_backfill.sql` preserves pre-existing undated trial service as ACTIVE. Fresh and upgrade migrations passed. `scripts/phase7-trial-integration.ts` and the Website Chat drill passed dated eligibility, expiry, notification dedupe, sponsorship, and retention of data. See `docs/phase7-trial.md`.
