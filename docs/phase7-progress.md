## Milestones

1. Baseline and audit — source reading, code inventory, clean-tree check, baseline tests completed. Continue recording findings as implementation reveals them.
2. Provider configuration — official OpenAI SDK, endpoint capability validation, primary/fallback vision, ElevenLabs configuration, mocked contract tests, live endpoint drill when credentials are provided.
3. Browser Use cutover — official open-source Python worker, TypeScript bridge, controlled-site validation and removal of CDP production code.
4. Real Web Chat — durable visitor sessions, production adapter and transport, end-to-end and tenant-security tests.
5. Facebook comments — verified Meta contract, normalization, policy/classification, safe actions, persistence, analytics and fake Meta drill.
6. Product/operations — role-scoped analytics, trial lifecycle, flags/notifications, evaluation, retention/offboarding, backup/restore and health.
7. Final validation — database smoke, `bun run check`, both builds, browser integration, release blockers, `docs/completion/phase7.md`, scoped commits and clean tree.

## Validation so far

The endpoint probe and ElevenLabs transport were exercised with controlled mock endpoints; no live provider credentials were available. A later audit caught the Responses adapter omitting version tone/language/disclosure instructions; it now transmits those immutable settings as system instructions with a regression test.

The gateway pins public DNS and permits only Chat Completions for the configured model. Per-session HTTPS CONNECT proxy, private screenshot cleanup, policy and token checks are wired. A two-session drill exposed the old 256 PID limit; the final Docker profile uses a two-session worker cap, 1024 PID and 2 GiB memory limits. After the old driver was removed, `bun scripts/phase6-browser-integration.ts` passed open/extract/type/click/screenshot/close, denial, cancellation, timeout, and safe progress. `bun scripts/phase7-browser-restart.ts` passed two-tenant page and screenshot isolation, stale-session rejection after worker restart, and new-session recovery. `bun run check` passed with 73 tests and 396 assertions. Live model-backed research remains unverified without an approved endpoint/key.
